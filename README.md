Like it or not, I do get BSOD every now and then. To fix my Windows machine, I have to search up commands on my phone, which I'm tired of doing so. Therefore, I decided to learn a little bit of Batch scripting so that I can make a simple script that automatically runs the commands in question.

Same goes for when Wi-Fi in Action Center says `No internet, secured`. Most tutorials teach bullshit like `ipconfig /flushdns` (delete temporarily stored DNS records for fucking god's sake 🫩), so I got the commands from [memstechtips](https://memstechtips.com/fix-slow-internet-windows-11/) whom I watch his YouTube videos frequently.

I rarely if not ever have a duplication file issue but in case I do, I might use <abbr title="documentation is readable">this Chinese guy's PowerShell script</abbr>: https://github.com/zouyonghe/remove-duplicate-files

Right now it's just these two tasks, because most of my other ones are already automated/have software to do so, like PowerToys' PowerRename utility. If I ever write another `.bat` file because I couldn't automate it/find a software, then I'll upload it here.
